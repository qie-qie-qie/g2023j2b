# 星轨课间 · 六师战斗学园 / g2023j2b

[点击在线游玩](https://qie-qie-qie.github.io/g2023j2b/)

三款小游戏：**六师对决**（横版格斗、三波敌人、最终首领）、**星轨疾行**（双跳、冲刺、射击、千米跑酷）和 **合成世一班**（经典碰撞合成）。

六位老师均可在动作游戏中出战：牢（化学，女）、C（语文，男）、振（数学，男）、只（生物，男）、米（英语，男）、蛋（物理，男）。每位老师有专属学科技能与终结技名称、配色和角色演出。

原创二次元形象由 AI 生成，根据学科与性别虚构设计，并非老师真实肖像。画风参考科幻二次元 RPG，没有使用现有游戏角色或提取素材。角色图与生成提示词见 ARTWORK.md、artwork-prompt.txt。

## 操作

- A/D 或左右箭头：格斗移动。
- 空格/W/上箭头：双段跳。
- 按住 J：连续普攻或跑酷射击。
- K：闪避/冲刺破障；E：学科技能；Q：满能量终结技。
- P/Esc：暂停。切到后台会自动暂停。
- 手机提供触控按钮，推荐横屏。

这是单人2D网页游戏。动作游戏纪录保存在本机；合成游戏保留原来的班级云端接口，该服务的登录和上传尚未验证。

## 下载与源码

下载仓库后直接打开 index.html，无需安装。完整项目、原版快照及24组回归测试见 [full-source.zip](full-source.zip)。可编辑的动作逻辑、画面和界面模块同时公开在 combat-model.mjs、battle-renderer.mjs、academy.mjs，修改后运行 `python3 build-academy.py` 重新生成页面脚本。

原合成游戏：https://github.com/qie-qie-qie/Git 。保留原仓库不变。
